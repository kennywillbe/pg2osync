NOTE: on PostgreSQL, set `max_slot_wal_keep_size` on the server before this

  ALTER SYSTEM SET max_slot_wal_keep_size = '10GB';
  SELECT pg_reload_conf();

An unread replication slot retains WAL until the database's disk is full.
Past the limit PostgreSQL invalidates the slot instead, and pg2osync falls
back to a full initial load — expensive, but the database stays up.
